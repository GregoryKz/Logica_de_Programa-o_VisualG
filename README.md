# 🧠 Lógica de Programação com VisualG

Repositório dedicado aos estudos e exercícios de **Lógica de Programação** desenvolvidos utilizando o **VisualG**.  
Este material faz parte do processo de aprendizado dos conceitos fundamentais de programação, com foco em lógica, algoritmos e raciocínio computacional.

## 📌 Sobre

O VisualG é uma ferramenta educacional muito utilizada no ensino de lógica de programação, pois permite escrever algoritmos em **português estruturado**, facilitando o entendimento para iniciantes.

Este repositório reúne exercícios e exemplos criados durante aulas e estudos, servindo como material de apoio e consulta.

## 🧠 Conteúdos Abordados

Os exercícios contemplam temas como:

- 🟢 Introdução à lógica de programação
- ✍️ Entrada e saída de dados
- 🔢 Variáveis e tipos de dados
- ➕ Operadores aritméticos, relacionais e lógicos
- 🔀 Estruturas condicionais (`se`, `senao`)
- 🔁 Estruturas de repetição (`para`, `enquanto`, `repita`)
- 📐 Algoritmos básicos
- 🧩 Exercícios de raciocínio lógico

## 🚀 Tecnologias Utilizadas

- 📘 **VisualG**
- 🖥️ Ambiente educacional para execução de algoritmos
- 📄 Arquivos `.alg`

## 🛠️ Como Usar

1. Faça o download e instale o **VisualG**.
2. Clone este repositório:

   ```bash
   git clone https://github.com/GregoryKz/Logica_de_Programa-o_VisualG.git
Abra o VisualG.

Carregue os arquivos .alg disponíveis no repositório.

Execute os algoritmos para visualizar o funcionamento passo a passo.
